Understand the evidence

Methodology

ICLayout-Bench evaluates AI agents on the physical realization of integrated circuits. Source case scores and verification labels come from the Public evaluator. This website adds reviewed publication and comparison; it never reruns or changes evaluation results.

01 / PHYSICAL VALIDITY

Is the layout valid?

Check the task’s declared DRC, connectivity and geometry requirements.

02 / CIRCUIT FUNCTION

Does the circuit work?

Check electrical requirements across the declared operating conditions.

03 / QUALITY

How good is the design?

Apply the task’s quality rule, then compare compatible evaluation conditions.

A case score and a leaderboard score answer different questions.

A case score follows one task’s rules. A board combines compatible results across its published circuit selection and weights. Missing coverage stays visible.

Evaluation conditions and comparability

Compare conditions, not names

Conditions retain model, harness, effort and recorded configuration. Each selected circuit context binds a task, tool identity, budget, scoring method and verification level. Contexts that differ remain separate selections.

Leaderboard aggregation and coverage

Weighted aggregation

Each finite recorded score is normalized as 100 × value / recorded reference (scores may exceed 100). Unknown or invalid scales and evaluation errors are missing measurements. A recorded failure or no-submission score of zero remains a measured zero. We average all eligible repetitions for a condition and context, never select the best run. An official comparison requires complete measurements and publication of the entire imported repetition cohort.

Weighted score = Σ(weight × normalized repetition mean) / Σ(selected weights)

All weights must be positive and finite. Official boards require complete coverage. Incomplete conditions are visible but unranked. Custom comparisons can explicitly count missing measurements as zero. The denominator always includes every selected circuit; missing weights never redistribute. Equal scores receive equal ranks.

Repetitions and coverage

Repetitions and coverage

The platform averages all imported runs in a condition/context, preserving different sessions even if they have the same repetition number. Import complete collections: the website cannot discover experiments or planned repetitions that were never supplied. Published rankings show their exact included run links.

Verification and publication

Verification & publication

Local development, service-recorded and verified evaluations are distinct evidence levels. Import and website publication never promote an evaluation. The first release accepts source-bound Public catalog circuits; unrestricted hidden-task archives cannot be published through this workflow. Results and assets require separate reviews. Withdrawal removes their public API and file access immediately; previously downloaded copies cannot be recalled.

Participation

Run experiments using the Public participant runner. This website currently focuses on operator-maintained experiments, reviewed publication and comparisons. Participant accounts and self-service uploads are deferred. Source labels do not change recorded scores or verification metadata.
