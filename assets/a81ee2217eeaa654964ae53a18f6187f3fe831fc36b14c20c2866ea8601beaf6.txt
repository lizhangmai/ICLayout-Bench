** AUTHORED TEMPLATE — ldo/psrr: AC supply rejection (Vdd -> Vout), closed loop.
** Inject AC=1 on the supply; psrr_vdd_db = -vdb(vout) (output rejection in dB). The feedback loop
** stays naturally closed (vout feeds the internal divider), so no loop-break trick is needed.
** Bindings: DUT PORT_LINE VDD ILOAD COUT PPD FSTART FSTOP FMEAS PDK_INCLUDE.
* Pinned upstream LDO fixture; existing IHP LV circuit and external bias.
.lib /workspace/support/models/cornerMOSlv.lib mos_tt
.lib /workspace/support/models/cornerCAP.lib cap_typ
.lib /workspace/support/models/cornerRES.lib res_typ
.include dut.spice
.temp 27
.option rshunt=1e12 reltol=1e-5 abstol=1e-14 vntol=1e-8 method=gear maxord=2
IBIAS vdd nbias 20u
VREF vref 0 0.5
VFB sense fb 0


.param VDD=1.2

Vdd  vdd 0 dc {VDD} ac 1
Vss  vss 0 dc 0
Iload vout 0 dc 0.1m
CLoad vout 0 1u

XDUT vdd vout vss nbias vref fb sense ldo_008_fer_mirror_ota

.control
  set filetype=binary
  set noaskquit
  ac dec 20 10 10meg
  meas ac vout_db FIND vdb(vout) AT=1k
  let psrr_vdd_db = 0 - vout_db
  print psrr_vdd_db
  write ac.raw all
  quit
.endc
.end
